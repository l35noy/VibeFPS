## 4. Архитектурные инварианты

### 4.1 Слои коллизий (Collision Layers)
| Слой | Имя | Назначение |
|---|---|---|
| 1 | `world` | Статическая геометрия уровня, стены, пол |
| 2 | `player_body` | Тело игрока (`CharacterBody3D`) |
| 3 | `enemy_body` | Тело врага (`CharacterBody3D`) |
| 4 | `enemy_hurtbox` | Зона получения урона врагом (`Area3D`) |
| 5 | `projectile` | Снаряды оружия (`Area3D`) |
| 6 | `interactable` | Точки взаимодействия (магазин, двери) |
| 7 | `player_hurtbox` | Зона получения урона игроком (`Area3D`) |

### 4.2 Навигация и пороги
- `path_desired_distance = 1.0` (порог смены промежуточной точки пути).
- `target_desired_distance = 0.5` (дистанция остановки у цели; строго меньше суммы радиусов хитбоксов 0.8 м для срабатывания урона).
- Навмеш: `cell_height = 0.25`, bake только по коллайдерам геометрии (`geometry_parsed_geometry_type = 1`, `collision_mask = 5`).

### 4.3 Смена сцен и состояние
- Все переходы между сценами осуществляются исключительно через `GameState.enter_location(id)` и `GameState.return_to_lobby(reason)`.
- Управление игрока активно только при захвате мыши: `InputGate.is_play_input_allowed(Input.mouse_mode)`.
