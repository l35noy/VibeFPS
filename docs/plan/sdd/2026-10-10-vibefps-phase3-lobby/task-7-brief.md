# Task 7: Падение с высоты = смерть → лобби (пост-ревью правка владельца)

**Status:** ready
**Date:** 2026-10-10
**Проект:** VibeFPS (Godot 4.7.2 stable, GDScript, Jolt)

## Зачем

Владелец (ручная проверка) подтвердил: смерть от контактного врага → возврат в
лобби — правильно (Task 5, не трогаем). Новое требование владельца:
**падение с высоты считать смертью — игрок после него появляется в лобби.**

Сейчас падение устроено иначе (инвариант старого фундамента): при
`global_position.y < fall_limit` игрок телепортируется на точку появления **без
восстановления здоровья** (`player.gd:272-273` → `_respawn()`). Это надо
заменить на путь смерти.

## Требования

### R7.1 `player.gd` (единственная логика)
- Выделить переход «смерть» в один метод (напр. `_die(reason: String)`),
  используемый и летальным уроном, и падением:
  - `take_damage`: при обнулении здоровья → `_die("death")` (поведение Task 5
    сохраняется как есть; см. `player.gd:105-122`).
  - падение (`y < fall_limit`): считать смертью → выставить здоровье 0,
    испустить `health_changed(0, max_health)`, затем `_die("fall")`.
- **Контракт смерти сохранить ровно как в Task 5:** сигнал `died` испускается
  СТРОГО один раз, и в момент его испускания здоровье уже 0 (`enemies.gd:580-583`
  это проверяет). Значит падение обязано довести здоровье до 0 ДО `died.emit()`.
- **Ровно один раз за смерть и для падения.** Важно: при подменённом
  `scene_changer` (записывающая заглушка в тестах) сцена реально не меняется, и
  если игрок остался ниже `fall_limit`, ветка падения в следующем кадре зашла бы
  повторно. Нужен гейт (напр. `is_alive()` как у `take_damage`, и/или явный флаг),
  чтобы `died`/`return_to_lobby` не повторялись каждый кадр.
- Переход при смерти без изменений: `/root/GameState` есть →
  `gs.return_to_lobby(reason)`; нет → fallback `_respawn(true)` (только для
  headless/сцен без автозагрузки). Прод-путь всегда идёт через GameState (спека
  §6.1: прямой `change_scene_to_file` в игровых сценах запрещён).
- Обновить устаревший комментарий `player.gd:276-285` (`_respawn`): тезис
  «падение за карту здоровье не восстанавливает» больше не верен — падение это
  смерть. `_respawn(restore_health)` оставить как fallback-механику.
